# Source audit and evidence ledger (2026-10-23)

## Scope of this version

- **Primary referenced index**: [ThePatternSite Chart Patterns](https://www.thepatternsite.com/chartpatterns.html), attributed to Thomas Bulkowski.
- **Transcription boundary**: index headings and named entries were collected using public/search-index views because direct machine fetching of the main site was blocked with HTTP 403 in the research environment. Entries were grouped into sections from numerical headings through W–Z. No hidden member content is accessed.
- **426 index rows** in the curated transcription, **383 unique normalized records**, **43 exact normalized repeated occurrences** across index sections. Differences in case, punctuation, aliases and taxonomy remain distinct when the source lists them differently. This is **index-level coverage for the collected index view**, not a proof that the live website contains only 383 concepts or that all live source pages were visited.
- **38 concept families** are organizational labels introduced by this repository, not official source categories.
- **35 entries** have a separately checked candidate direct page URL based on public search. Verified URL status means URL evidence, **not independent verification of detailed page text or historical pattern claims**.
- **301 family-level records, 35 URL-verified records, 47 contextual records** (including reference/research topics). “Family-level” is **not** a certification of exact author-specific thresholds.
- **334 SVG figures** generated by this project for educational purposes. Each is a *stylized schematic of its family*, not an original-site image, screenshot, copied chart or historical price example. Some patterns share geometry; individual images should not be used as proof of a unique author-specific formation.
- **383 original Markdown descriptions** use family-level criteria and variant-specific precautions. Important: some names may refer to niche author-specific setups with an exact rule unavailable in the source index; those entries expressly require primary-source verification.

## Confidence semantics

| Value | Interpretation | Limits |
|---|---|---|
| `reference_verified` | A likely individual original page URL was corroborated through public search. | Does not confirm that all unique textual criteria or statistics were examined. |
| `family_level` | Named index entry, original explanation of broad family, schematic if geometrical. | Entry-specific trigger, exact ratio, target and win rate may be unverified. |
| `requires_source_review` | Rare author-specific setup without verified definition. | Do not infer rules from its name alone. Currently no entry carries this status; some `family_level` records still require review as warned in their notes. |
| `context_only` | Supplementary context, background, event, research or method instead of a standalone price geometry signal. | Not a pattern-recognition detector. |

## Material deliberately *not* bundled

- Thomas Bulkowski's original page descriptions, books, photographs, illustrations and historic chart captures.
- The site's proprietary/research performance tables, failure rates, odds, rankings, targets, success figures and trade simulation results.
- Claims that all listed patterns were backtested or that the site provides machine-readable licensing for redistribution.
- Automatic recognition for all 383 entries. Only a named, tested micro-subset is implemented.

## How to independently verify a single pattern

1. Look it up in [our JSON](../skills/pattern-atlas/data/catalog.json) and record the English title, alias and source URL.
2. Open the **author's exact page** (when available). Check definitions of boundaries, minimum counts, trend prerequisites, breakout and false signals; note publishing date and updates.
3. Rephrase the methodology in original language; attribute nontrivial sourced factual claims and avoid copying the source text or images.
4. Define formal recognition rules and human-labelled positive/negative charts, **as-of** dates, market/corporate-event adjustment logic.
5. Backtest with survivorship controls, date-based holdout, realistic fees/slippage and a statistical uncertainty interval; avoid leakage from future pivots.
6. Mark `reference_verified` only for URL, and add a separate definition/content review field to future schema versions if the specific text is independently validated.

## Research provenance / known unknowns

The main site's robots and 403 behavior can change. An index can change after this audit date. Entries may be missing, misspelled or duplicated beyond simple normalization, especially where author names differ from standard terminology. No comprehensive verification of 383 source pages was feasible. Please do not represent this release as a full-text clone or a content-complete reproduction of ThePatternSite. The repository is complete *as a usable agent skill and curated educational index*, subject to the disclosure above.
